# U8 Football Coach AI

An AI-powered coaching assistant for U8 football coaches. Generate fun, safe, and age-appropriate training drills and session plans for children aged 6 to 8.

## Features
- Generate single drills from a description
- Generate complete session plans with warm-ups, main activities, and cool-downs
- Multilingual output: English, French, and Arabic
- Full right-to-left (RTL) support for Arabic

## Built With
- Streamlit
- Claude API (Anthropic)
- Python

## How to Run Locally
1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Create a `.env` file with your `ANTHROPIC_API_KEY`
4. Run: `streamlit run app.py`

## Deployment
This app is deployed on Streamlit Cloud.
